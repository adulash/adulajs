# اللغات

النسخة الإنجليزية: [Languages](../languages.md)

العربية هي اللغة الأساسية لكل نظام مبني على AdulaJS. كل شاشة ورسالة وتسمية موجودة بالعربية، أما اللغات الأخرى فطبقة اختيارية يفعّلها النظام ويختارها كل مستخدم لواجهته هو. الإنجليزية ليست مطلوبة أبدًا. القرار في [ADR 041](../decisions/041-optional-languages.md).

## ما يفعله مدير النظام

اللغات الإضافية معطّلة افتراضيًا، فلا تُعرض إلا العربية. لتسمح للمستخدمين باختيار الإنجليزية، أضفها إلى `languages` في `config/adula.ts`:

```ts
const adulaConfig: { languages: string[]; timeZone: string } = {
  languages: ['ar', 'en'],
  timeZone: 'Asia/Riyadh',
}
```

`timeZone` المنطقة الزمنية للنظام (اسم IANA مثل Asia/Riyadh)، وبها تُحسب أيام استحقاق سير العمل وأيام التفويض؛ اضبطه على منطقة شركتك.

العربية متاحة دائمًا وتأتي أولًا دائمًا. حين تُفعَّل أكثر من لغة تظهر في صفحة الملف الشخصي بطاقة «لغة الواجهة»، يختار منها كل مستخدم لغته (تُخزَّن في `users.language`، والافتراضي `ar`). إذا أُزيلت لغة من القائمة لاحقًا يرى من اختارها العربية مجددًا، ويبقى اختياره المخزَّن محفوظًا.

## ما يتبع لغة المستخدم

مثال: الموظف «جون» في فرع الشركة الخارجي يختار الإنجليزية. بعد تسجيل دخوله يحصل على:

- `<html lang="en" dir="ltr">`، وخصائص Inertia `locale` و`dir` و`languages` و`messages`. تبقى العربية من اليمين إلى اليسار، وكل لغة تعلن اتجاهها.
- نصوص الإطار التي يترجمها دليل الإنجليزية المرفق: رسائل التحقق في VineJS، ورسائل `AdulaError`، ونصوص أخطاء معالج الاستثناءات، والتنبيهات بعد إعادة التوجيه (flash)، وهيكل مساحة العمل، والقائمة العامة للمورد ونموذجه وشاشات السجل.
- تسميات الموارد والوحدات والحقول من `label.en` حين يعرّفها المورد.

أما الزوار (صفحات الدخول واسترداد كلمة المرور والتسجيل)، والطلبات الموثَّقة برمز API، والأخطاء التي تقع قبل تحديد اللغة (مثل انتهاء رمز الحماية CSRF أو مسار غير معروف)، فيرون العربية.

## التسميات: `label.<lang>` يرجع إلى `label.ar`

`label.ar` مطلوبة في الموارد والحقول وتسميات السجل والإنشاء والقوائم المرجعية للوحدات والوحدات نفسها. كل لغة أخرى اختيارية:

```ts
defineResource({
  name: 'receipts',
  label: { ar: 'الإيصالات' }, // shown in every language
  fields: {
    reference: { type: 'string', label: { ar: 'رقم الإيصال', en: 'Reference' } },
  },
  // …
})
```

التسمية التي تذكر لغة يجب أن تعطيها نصًا: `en: ''` يُرفض لأنه خطأ على الأرجح. وحيث تغيب `label.<lang>` تظهر التسمية العربية. وثيقة OpenAPI بالإنجليزية وترجع إلى التسمية العربية بالطريقة نفسها. والقوائم المرجعية للوحدات تخزّن نصها العربي في `label_en` إن لم يكن لها تسمية إنجليزية.

## دليل الرسائل

دليل الرسائل الأساسي (`arabicMessages` في الحزمة `adula`) يربط مفاتيح ثابتة بالنص العربي الذي يُنتجه الإطار بالضبط، مقسَّمًا إلى أقسام:

| البادئة | المحتوى |
|---|---|
| `validation.*` | قواعد VineJS (`validation.required`، `validation.min`) |
| `errors.*` | رسائل `AdulaError` ونصوص أخطاء HTTP، حسب رمز الخطأ |
| `flash.*` | التنبيهات بعد إعادة التوجيه |
| `ui.*` | نصوص واجهة النظام المرجعي و`@adula/ui` |

- `translate(key, language, params)` تعيد النص باللغة المطلوبة، وترجع إلى العربية للمفتاح الذي لا تترجمه اللغة، وتستبدل العناصر النائبة `{name}` من `params`.
- `localizeText(text, language)` تترجم النص العربي الذي يطابق مدخلًا في الدليل تمامًا، فتُترجَم الشيفرة التي ما زالت تكتب نصوصًا عربية عند الحدود، ويبقى الناتج العربي مطابقًا حرفًا بحرف.

وسيط اللغة (middleware) يشغّل كل طلب داخل `runWithLanguage(language, …)`، فتستخدم `currentLanguage()` كلٌّ من أخطاء `AdulaError` المنشأة أثناء الطلب ورسائل VineJS (عبر `installCatalogMessages(vine, registry.all())` في `start/validator.ts`). مكونات الواجهة تُبقي نصها العربي وتبحث عنه في الخاصية `messages` (نص عربي ← ترجمته، وفارغة للعربية) عبر `useMessages()` من سجل `@adula/ui`.

## إضافة لغة

1. اكتب دليلًا بالمفاتيح التي تترجمها؛ المفاتيح غير المترجمة تظهر بالعربية.

   ```ts
   // start/languages.ts
   import { registerLanguage } from 'adula'
   import { frenchMessages } from '../languages/fr.js'

   registerLanguage('fr', frenchMessages, { name: 'Français', dir: 'ltr' })
   ```

   يرفض `registerLanguage` المفاتيح التي لا يعرّفها الدليل العربي والنصوص الفارغة، ويشترط اسم عرض للغة، ولا يسمح باستبدال العربية. تسجيل الرمز نفسه مرة أخرى يدمج الدليلين، فيمكنك تعديل مدخلات دليل الإنجليزية المرفق.
2. أضف رمز اللغة إلى `languages` في `config/adula.ts`.
3. أضف `label.fr` إلى الموارد والحقول والقوائم المرجعية التي تريد ترجمتها.

## ما يبقى بالعربية

- بيانات العمل: السجلات، وتسميات خيارات القوائم المرجعية في النماذج والجداول، والوحدات التنظيمية، وأسماء الأدوار، وقوالب الرسائل.
- عناوين رسائل البريد ونصوصها، والإشعارات المخزَّنة، وأخطاء صفوف الاستيراد.
- الشاشات التي لم تُنقل إلى الدليل بعد: صفحات الإدارة، وإسنادات السجلات، وسير العمل والتعاون، واستيراد CSV، والتقويم الهجري. وبعض عناصر التحكم المشتركة (القائمة المنسدلة للاختيار، والقوائم، والتبويبات، والتنبيهات المنبثقة، والتقويمات) ما زالت تُعرض من اليمين إلى اليسار حتى في لغة اتجاهها من اليسار إلى اليمين.
- الرسائل المبنية بقيم مدرجة لم تتحول بعد إلى قوالب في الدليل (مثل رسالة قفل الدخول مع عدد الدقائق)؛ تظهر بنصها العربي إلى أن تتحول.
